# hostparse — ホスト固定長ファイル パースツール

SJIS(CP932)・改行なしの固定長レコードファイル(メインフレームから転送したデータなど)をパースして、テキストまたはCSVに変換するツール。**パック10進(COMP-3)項目の展開に対応**。

Python 3.10 以降の標準ライブラリのみで動作(追加インストール不要)。

## GUI版

**`hostparse_gui.bat` をダブルクリック**(または `python hostparse_gui.py`)で起動。

使い方の流れ:

1. **入力ファイル** を「参照...」で選択(レコード長が分かれば入力、不明なら「自動検出」)
2. **レイアウト** を用意 — いずれかの方法で:
   - 「コピー句 読込」… COBOL COPY句ファイルから自動生成(レコード長も設定される)
   - 「レイアウトCSV 読込」… 既存のレイアウト定義を読込
   - 「推測」… データから自動推測(結果は要確認)
   - 手動 … 下部の「フィールド編集」で 名前・開始位置・バイト数・形式・小数桁 を入力して「追加」。行を選択すると編集欄に入るので修正して「更新」
3. **「プレビュー更新」** で先頭200件を確認(「16進ダンプ」タブで生バイトも見られる)
4. **出力** で CSV/テキスト、UTF-8/ANSI を選んで「変換実行」(進捗バー表示、大きなファイルも中断なく変換)

作ったレイアウトは「CSV保存」でファイル化でき、CLI版の `-l` でもそのまま使える。

ファイル選択・自動検出・推測・プレビューはすべてバックグラウンドで実行されるので、
ネットワークドライブやクラウド同期フォルダ上の大きなファイルでもウィンドウは固まらない。
これらの処理が読むのは先頭の一定量だけなので、所要時間はファイルサイズに依存しない
(92MB でも 1MB と同じ速さ)。

## CLI版の基本的な使い方

```powershell
# ① コピー句(COBOL COPY句)がある場合 — そのまま渡すだけ
python hostparse.py data.dat -c copybook.cpy -o out.csv

# ② レイアウトが分かっている場合 — レイアウトCSVで指定
python hostparse.py data.dat -l layout.csv -o out.csv

# ③ 少数の項目だけ手動指定 (名前,開始位置,バイト数,形式[,小数桁])
#    ※ 部分指定のときはレコード長 -r が必須
python hostparse.py data.dat --field "社員番号,1,5,9" --field "給与,26,5,パック,2" -r 46 -o out.csv

# ④ レイアウト不明 — 推測させる (レコード長も自動検出)
python hostparse.py data.dat --guess
#    → data.dat.layout.csv にレイアウト案が保存されるので、確認・修正して ② で再実行
```

## 出力の選択

| オプション | 説明 |
|---|---|
| `--format csv` / `--format text` | 出力形式。省略時は出力ファイルが `.csv` なら CSV、それ以外はテキスト |
| `--encoding utf-8` (既定) | UTF-8 で出力。CSV は BOM 付きなので Excel でそのまま開ける |
| `--encoding ansi` | ANSI (CP932 / Shift_JIS) で出力 |
| `-o FILE` | 出力ファイル。省略時は標準出力 |

テキスト形式は各項目を桁揃えして出力する(パック項目は数値として右寄せ表示)。
`--header` でテキストにも見出し行、`--no-header` で CSV の見出しを省略。

## 形式コード

| コード | 意味 | 説明 |
|---|---|---|
| `X` (半角) | 半角文字 | 英数記号。半角カナも可 |
| `K` (カナ) | 半角カナ | Xと同じ変換。レイアウト上の区別用 |
| `N` (全角) | 全角文字 | SJIS 2バイト文字 |
| `9` (数値) | ゾーン数値 | `S9` で符号付き(オーバーパンチ対応) |
| `P` (パック) | パック10進 | COMP-3。符号ニブル C/F=正, D=負 |
| `B` (バイナリ) | 2進数値 | COMP/BINARY。ビッグエンディアン |

小数桁を指定すると `1767826` → `17678.26` のように小数点を挿入する。
数値の先頭ゼロは既定で除去(`00123` → `123`)。維持したい場合は `--keep-zeros`。

## レイアウトCSVの書式

ヘッダ行あり(日本語・英語どちらでも可)。開始位置は **1始まり** のバイト位置。

```csv
名前,開始,バイト数,形式,小数桁
社員番号,1,5,9,
氏名カナ,6,10,K,
氏名漢字,16,10,N,
給与,26,5,P,2
部署コード,31,2,B,
入社日,33,8,9,
```

## コピー句の対応範囲

- `PIC X/A/N/9/S9…V9…`、括弧の繰返し `9(7)V99` と連記 `999V99` の両方
- `COMP-3`(パック)、`COMP/BINARY`(バイナリ)、`PACKED-DECIMAL`
- `OCCURS n TIMES`(`項目名(1)`, `項目名(2)`… に展開)
- `REDEFINES`(同一位置にオーバーレイ。両方の項目が出力される)
- `FILLER` は出力から除外
- 固定形式(1〜6桁目の行番号・7桁目の `*` コメント)/自由形式とも可
- 編集項目(`ZZZ,ZZ9` など)は文字として扱う

コピー句の文字コードは自動判定(UTF-8 / SJIS)。`--copybook-encoding` で明示も可。

## その他のオプション

| オプション | 説明 |
|---|---|
| `-r, --record-length N` | レコード長(バイト)。コピー句・全項目レイアウトなら省略可 |
| `--show-layout` | レイアウトを表示するだけで変換しない(位置確認に便利) |
| `--save-layout FILE` | 解決したレイアウトをCSV保存(コピー句→レイアウトCSV変換にも使える) |
| `--limit N` / `--skip N` | 先頭N件のみ / 先頭N件を読み飛ばし(お試し変換に) |
| `--delimiter STR` | テキスト形式の項目区切り(既定: 半角空白) |

## 変換エラーについて

パック項目のニブル不正やゾーン数値の非数字は、その項目だけ `#ERR:<16進>` と出力して処理を続行する(件数は最後に stderr へ表示)。#ERR が多発する場合はレイアウトのズレ(開始位置・レコード長の誤り)がほぼ確実なので `--show-layout` と `--limit 10` で確認するとよい。

## 性能の目安

約 20万レコード/秒・9MB/s(46バイト×200万レコード=88MB を約10秒)。
チャンク読み込み+項目ごとの事前生成変換関数で、ファイルサイズによらずメモリ使用は一定。

レコード長の自動検出は先頭1MBのみを読み、列の均質さの判定を
`bytes.translate` と多倍長整数のビット演算でまとめて行うため、
ファイルサイズや約数の個数によらず 0.1 秒以内に終わる。
